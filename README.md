## References and Acknowledgements

This project builds upon existing research and uses publicly available research resources. The following sources are acknowledged:

### Dataset

The **M4Human** dataset was used in this project for training and evaluation of the model. The dataset was developed by Fan et al.

- Repository: https://github.com/FanJunqiao/M4Human
- Project website: https://fanjunqiao.github.io/M4Human-site/

**Citation:**

Fan, J., Zhou, Y., Yang, Y., Cui, X., Zhang, J., Xie, L., Yang, J., Lu, C. X., & Ding, F. (2026). *M4Human: A Large-Scale Multimodal mmWave Radar Benchmark for Human Mesh Reconstruction*. Proceedings of the IEEE/CVF Conference on Computer Vision and Pattern Recognition (CVPR), 42836–42846.

### Research and Methodological Inspiration

The design and implementation of this project were informed by the research and codebase of **mmDiff**, which explores diffusion-based human pose estimation using RF-vision and mmWave radar point clouds.

- Repository: https://github.com/FanJunqiao/mmDiff
- Project website: https://fanjunqiao.github.io/mmDiff-site/

**Citation:**

Fan, J., Yang, J., Xu, Y., & Xie, L. (2024). *Diffusion Model is a Good Pose Estimator from 3D RF-Vision*. European Conference on Computer Vision (ECCV 2024).

### Attribution

The M4Human dataset and mmDiff research are credited to their respective authors. The use of these resources and research ideas is acknowledged; the modifications and additional implementation work in this project are documented separately where applicable.
